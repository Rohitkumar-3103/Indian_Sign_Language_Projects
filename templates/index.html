ISL Hand Guide

Two-Handed vs Single-Handed

Unlike ASL, Indian Sign Language features extensive two-handed gestures:

  • Green Skeleton: Right / Dominant Hand
  • Cyan Skeleton: Left / Secondary Hand
  • Vowels A, E, I, O, U use right index touching left fingertips!

Survey of Research Papers in Project Repository
Title / Publication Architecture / Method Gestures / Scope Key Findings & Integration
1. A Comprehensive Approach to ISL Recognition (Rawat et al. 2024) MediaPipe Holistic + LSTM Dynamic Words & Static Letters 96.97% • Validates sequential temporal debouncing and 543 holistic landmarks.
2. Hand Gesture Recognition Using Deep Learning (Vashisth et al. 2023) Deep CNN + Preprocessing 35 Classes (1-9, A-Z) 92.83% • Demonstrates raw CNN vulnerability to lighting; motivates landmark invariance.
3. Integrative Survey on ISL Recognition & Translation (Damdoo 2025) Comprehensive Survey 100+ Studies (State of Art) State-of-Art • Establishes bimanual ISL mandate and bidirectional voice/sign architecture.
4. ISL Recognition Using SURF with SVM and CNN (Katoch et al. 2022) SURF + BoVW + SVM / CNN 35 Classes (1-9, A-Z) 99.17% / 99.64% • Proves rotation and scale-invariant descriptors maximize margin separation.
5. ISL Detection for Real-Time Translation (Singhal et al. 2023) MediaPipe + Random Forest 35 Classes (1-9, A-Z) 99.95% • Directly justifies Random Forest as the optimal fast classifier for coordinate data.
6. Indian Sign Language Recognition System (Rokade & Jadav 2018) Skin Color + PCA + ANN Static Alphabets 94.37% • Highlights classical color segmentation failures solved by our MediaPipe pipeline.
7. ISL Recognition System for Dynamic Signs (Singh & Mittal 2022) Optical Flow + MHI + LSTM Dynamic Phrases & Motion 97.23% • Guides our temporal hysteresis state machine and word hold confirmation.
8. ISL Recognition Using MediaPipe Holistic (Goyal & Velmathi 2023) MediaPipe Holistic + MLP Conversational Terms 90.00% • Confirms upper-body pose context resolves identical hand shape ambiguities.
9. ISL to Text/Speech Translation (Bhanu 2025) Keypoints + CNN + TTS Sign to Spoken Audio 93.67% • Validates integrated Text-to-Speech synthesis for deaf-hearing communication.
10. ISL Recognition Using ANN and SVM (Ekbote & Joshi 2017) Geometric Descriptors + SVM 32 Static Gestures 97.10% (SVM) • Proves margin-based classifiers excel on structured geometric hand features.
11. Real-Time Detection Using LSTM & Keypoints (Tharsan 2022) MediaPipe + Stacked LSTM Continuous Sentences 91.30% • Informs continuous sentence formation and phrase sequence accumulation.
12. SignSpeak: ISL Recognition with ML Precision (Mishra 2025) MediaPipe + Random Forest Dual-Hand Alphabets 94.50% • Corroborates our Random Forest model accuracy benchmarks (85.2%–94.5%).
13. Sign Comm: Real-Time ISL Using Deep Learning (Ilakkia 2024) Deep CNN + ResNet Inclusive Communication 97.00% • Directly mirrors our project mission of two-way inclusive interaction.
14. Two-Handed ISL Recognition Using MediaPipe (Awalkar 2025) Dual MediaPipe + Random Forest Two-Handed Alphabet 98.20% • Core empirical validation for our 156-dim invariant dual-hand feature vector.
15. Indian Sign Language Recognition (Maben et al. 2021) Contour Tracking + KNN Emergency & Daily Signs HCI Design • Provides human-centric accessibility guidelines for our web interface.
16. Real-Time Indian Sign Language Detection (IJERT 2021) Real-Time Edge CNN Live Webcam Feed 90.20% • Guides frame rate stabilization and canvas overlay rendering at 30 FPS.
17. Speech to ISL Translation Using NLP (Sharma et al. 2022) NLP + HMM + Video DB Speech & Text to ISL Phrases 86.6% NPS (83.3) • Direct architectural validation of our reverse Voice-to-Sign synthesis and character fingerspelling fallback.

Real-Time Sign Language Translator Leveraging Transformers (Khakha et al. 2026) 3-Layer Transformer + MediaPipe 26 Classes (44,200 Samples) • 76.6% Bimanual 97.40% Accuracy • Validates multimodal self-attention & proves two-handed coordinate spatial modeling directly aligns with our 156-dim feature extractor.
